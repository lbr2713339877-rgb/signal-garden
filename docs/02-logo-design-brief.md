# Signal Garden Logo Design Brief

## 从 V3 视觉系统提取的设计基因

### 核心概念
**A LIVING SIGNAL FIELD / 正在生长的信号场**

不是"雷达"，是**信号被测量的样子**：
- 有位置、有深度、有质量
- 正在形成、未完全稳定
- 被观测、被识别、被聚焦

### 视觉约束（来自 V3 token 系统）

| 维度 | 规则 |
|---|---|
| 色彩 | 黑色为主，彩色只作为**穿过玻璃的光**；暖白 `#F2F0EA` 不用纯白 |
| 材质 | 玻璃三层，圆角 ≤ 4px，**透明 > 填充** |
| 形态 | 裁切多边形、极细线条、字体片段 |
| 运动暗示 | 轻微不规则、有惯性、分层深度 |
| 禁止 | 圆形雷达、扫描波、发光圆球、霓虹边框 |

### 排版性格
- Display: Instrument Serif（高对比编辑衬线，单字重）
- Sans: Geist Sans（中性克制）
- Mono: IBM Plex Mono（档案感）
- 极端字号差（21:1）、紧密字距

---

## 三个方向

### Direction A — SIGNAL NOTATION / 信号记号

**性格**：档案、编号、系统标记

一个极简的符号系统，像科学记录里的标注：

```
┌─ S
│
└─ G
```

或用 Instrument Serif 的 **SG** 二字母组合，但做**不对称裁切**：
- S 被上半部裁掉 40%
- G 被下半部裁掉 30%
- 两个字母不在同一基线上（S 高 2px）
- 透明度 S=100%, G=68%（暗示深度）

颜色：暖白 `#F2F0EA` + 极细的冷青 `#73D9E8` 边缘高光（1px，仅左边缘）

适用场景：Favicon、系统标识、极小尺寸

---

### Direction B — FIELD APERTURE / 场的光圈 ★ 推荐

**性格**：空间、观测、聚焦

一个**不闭合的多边形框**，内部有三个不同深度的**玻璃切片**重叠。

视觉逻辑：
1. 外框是"观测窗口"，不闭合（左下角断开 12%）
2. 内部三个半透明平面，各自旋转不同角度（-8°, 0°, +5°）
3. 重叠处颜色叠加，形成深浅差异
4. 字母 **SG** 用 Geist Sans，极小字号，放在右下角作为系统标注

```
    ┌────────╮
    │    ╱╲  │
    │  ╱    ╲│
    │╱  ╱╲   │
         ╲ ╱ │
            SG
```

颜色分层：
- 外框：暖白 `#F2F0EA` 1px 描边
- 切片 1：冷青 8% 填充
- 切片 2：雾蓝 6% 填充
- 切片 3：薄荷 5% 填充
- 重叠处自然叠加

尺寸：正方形，最小 32×32px 可辨识，放大到 512×512px 不失细节

适用场景：主 logo、应用图标、社交媒体头像

---

### Direction C — SIGNAL ARRAY / 信号阵列

**性格**：节点、网络、生长

三个不同尺度的**点**，用极细线连接，但线是**断续**的（不是实线）：

```
    ●────
         ╲
          ●───
              ╲
               ●
```

三个点的大小比例：1.4 : 1.0 : 0.7（对应 V3 里的三层深度）

点不是实心圆，是**细环**（2px 描边，中空），最小的那个点只有外轮廓没有填充。

颜色：
- 大点：暖白 100%
- 中点：暖白 68%
- 小点：暖白 38%
- 连接线：冷青 `#73D9E8` 18%，断续（6px 实线，4px 间隔）

下方字标：**SIGNAL GARDEN** 用 Geist Sans 11px，字距 0.14em

适用场景：横版 logo、网站 header、印刷品

---

## 我的推荐：B（场的光圈）

理由：

1. **最能表达"观测"这个核心动作**——A 是记号（被动），C 是网络（关系），只有 B 是"正在看着什么"。
2. **玻璃材质能直接用上 V3 的视觉语言**——三层半透明平面就是 V3 token 系统里的 glass-1/2/3。
3. **不闭合的外框是记忆点**——"不完整"暗示"正在形成"，这是品牌核心。
4. **尺寸适应性最好**——从 32px 的 favicon 到 512px 的启动图标都能保持识别度。

从 A 采纳的：**SG 作为系统标注**放在右下角，保留档案感。

从 C 采纳的：**断续线**的概念，用在外框的断开处——不是直接消失，而是渐隐（opacity 100% → 0%）。

---

## 实现方案

用 **SVG**，不用位图。三个理由：
1. V3 的玻璃效果需要半透明叠加，SVG 的 `fill-opacity` 和 `mix-blend-mode` 能精确控制
2. 不同尺寸不需要多套文件
3. 可以加 CSS 动画（hover 时三个切片轻微位移）

技术栈：纯 SVG + 内联样式，不依赖外部 CSS。
